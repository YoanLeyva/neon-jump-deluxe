# 🎮 Neon Jump · Deluxe

**Jump higher. Dodge enemies. Collect power-ups. Beat your record.**

Neon Jump · Deluxe is a neon-inspired endless vertical platformer built entirely with HTML5, CSS3 and vanilla JavaScript.

Control a glowing character as it automatically jumps between platforms, avoids dangerous enemies, collects special power-ups and climbs higher to achieve the best possible score.

An arcade experience designed for both desktop and mobile devices, featuring smooth animations, synthesized sound effects and vibrant neon visuals.

## 🚀 Play the Game

**[Play Neon Jump · Deluxe](https://YoanLeyva.github.io/neon-jump-deluxe/)**

## ✨ Features

- **Endless vertical gameplay:** procedurally generated platforms and progressively challenging gameplay.
- **Responsive controls:** keyboard, mouse and touchscreen support.
- **Double jump:** perform an additional jump while airborne.
- **Power-ups:**
  - ⚡ Jump Boost: enhanced jumping ability.
  - 🧲 Magnet: attracts power-ups and nearby platforms.
  - 🛡️ Shield: protects against enemy collisions.
- **Moving enemies:** avoid dangerous neon creatures that appear as you progress.
- **Zen Mode:** a relaxed experience without enemies, including recovery after falling.
- **Particle effects:** glowing particles, trails, screen shake and neon animations.
- **Synthesized audio:** real-time sound effects using the Web Audio API.
- **Score system:** track your climbing height and personal best.
- **Local persistence:** best score saved using browser localStorage.
- **Mobile-friendly:** optimized canvas rendering for different screen sizes.

## 🕹️ Controls

### Desktop

| Action | Control |
|---|---|
| Move left | `←` or `A` |
| Move right | `→` or `D` |
| Double jump | `SPACE`, `↑` or `W` |
| Toggle Zen Mode | `Z` |
| Toggle sound | `M` |

### Mobile

- Touch the left side of the screen to move left.
- Touch the right side to move right.
- Swipe upwards to perform a double jump.
- Use the on-screen buttons to toggle Zen Mode and sound.

## ⚡ Power-ups

| Power-up | Effect | Duration |
|---|---|---|
| ⚡ Jump Boost | Enhanced jumping ability | 10 seconds |
| 🧲 Magnet | Attracts power-ups and nearby platforms | 8 seconds |
| 🛡️ Shield | Protects against one enemy collision | 12 seconds |

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript ES6+
- Canvas API
- Web Audio API
- Pointer Events API
- LocalStorage API

No external libraries, frameworks or assets required.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/YoanLeyva/neon-jump-deluxe.git
```

Navigate to the project directory:

```bash
cd neon-jump-deluxe
```

Open `index.html` in your browser.

Alternatively, use Visual Studio Code with Live Server.
